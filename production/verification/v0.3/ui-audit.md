# v0.3 UI/UX verification

範圍：電腦瀏覽器為主要平台；Chromium 模擬觸控尺寸作相容驗證。這是開發者流程檢查與啟發式介面審查，不是真人留存研究或手機實機認證。

## 已發現並修正

- P1：籌備階段誤把兩個正常影廳標成維修。原因是未開日時間 -1 與關閉時間 0 比較；改用共用的 hallUnderRepair，並加回歸測試。
- P1：電腦初始畫面底部控制列遮擋地圖下方。縮減重複的場景標題並依視窗高度分配地圖。
- P1：手機原有媒體規則隱藏了遊戲名稱。恢復名稱，並讓窄螢幕地圖預設 160% 方便觀察；全景按鈕可還原。
- P2：未上映電影整張卡片淡化，片商抽成等關鍵文字對比不足。只淡化圖片，正文維持正常對比，抽成字級提升。

## 實際驗證

- 第一焦點為可玩的戲院，第二為開始／暫停／速度，第三為所選區域及下一步安排。較完整的財務與小報位於下方，避免主場景塞滿數字。
- 所有主要流程有實際點擊證據：排片定價、升級、三種小遊戲、日結、新日、舊檔、離線保存。
- 390×844、720×1280、1080×2400 模擬觸控沒有頁面橫向溢出；導覽、區域選取及全景／縮放均可操作。補充結果見 mobile.json。
- 中文正文與主要操作採一般可讀字體，像素效果集中於遊戲美術。地圖小標籤可以放大，下方有同名區域按鈕。
- 鍵盤可操作按鈕、表單及地圖；焦點樣式保留。尊重減少動態設定，提示音預設關閉且不阻擋營運。
- 斷網後已載入的遊戲仍可操作與存讀檔；素材載入失敗顯示重試並阻止開始營業。

## 未驗證

六吋實際手機、螢幕閱讀器完整流程、手機 GPU／熱衰減及真人長期經濟節奏未驗證。手機並非此次主要目標平台。沒有內購或 Google Play 提交，相關評分不適用。
