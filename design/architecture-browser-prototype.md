# 瀏覽器原型的實作邊界

使用 Codex Game Studio 的原型流程、設計文件及驗證。保留 Godot 原始 PNG、AtlasTexture 與資源測試；這個可玩瀏覽器版本使用 ES modules + Canvas 2D，直接讀取同一 PNG 圖集及 atlas.json。不是把貼圖測試畫面冒稱 Godot 經營遊戲。

原因：現有工作台已使用 Canvas，首版可沿用素材並以原生 HTML 提供可操作、可讀取的排片、財務與分店介面。純資料模擬與畫面分離，使用 Node 的確定性測試驗證財務、事件、時間及存檔。

Studio 的 Godot 設定代表保留的引擎與貼圖來源軌道；瀏覽器可玩原型源碼位於 prototypes/browser。未新增或改寫 agents、skills、workflows。

本輪目標：實際貼圖場景、排片與定價、三崗位員工、自動小食、180 秒營業、0–2 事件／單店／日、三種可選小遊戲、買斷、第二店直接管理、週更新及本機存檔。

初始角色以程式繪製像素人物；正式角色動畫與地板材質仍可迭代，不阻止驗證玩法。經濟值與日長仍是試玩設定。
