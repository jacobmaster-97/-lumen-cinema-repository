# 光影大亨地圖編排器

使用者要求以 HTML 製作可拖動區域的互動元件，用來決定起始地圖模樣。這是獨立設計工具，不接入或部署目前遊戲。

## Open

- cinema-layout-editor.html：對話內互動元件，完整 literal HTML fragment；不依賴網路、圖片或外部程式庫，小於 1 MiB。
- index.html：獨立單一 HTML，下載後直接用瀏覽器開啟，不需伺服器；可以離線編排。
- 修改 fragment 後執行 `node design/tools/layout-editor/build.mjs` 同步獨立版。

## Controls

- 拖動影廳、售票、小食及洗手間，吸附至 7×7 方格。影廳 2×2，其餘 1×1。新開預設為使用者第二版已確認位置，洗手間入口向右；不把這些房間預設為開局啟用。已有本機或對話儲存的編排仍優先還原。
- 手機可先點區域，再點目標格；亦可輸入行／列、按方向按鈕或在區域上按鍵盤方向鍵。
- 地圖越界、房間重疊及佔用右下角固定入口會被拒絕。拖曳無效時保留原位置。
- 「鋪起始地板」及「擦除地板」可拖刷。初始只保留右下角一塊地板；起點不能擦除。
- 區域位置是規劃資料；勾「開局啟用此區」才加入開局，並補齊該房間地板。移動／取消啟用後舊地板保留為走道，不自動擦掉。
- 可選房間入口四個方向；檢查開局走道與各啟用區域入口是否連到固定起點。此為方塊級檢查，不代表座椅／家具級導航。
- 「只看開局」隱藏規劃中的房間，直接檢視真正開局地板及已啟用區域。
- 復原／重做最多保留 50 次操作；拖刷一整筆為一次操作。

## Save, export and handoff

- 獨立版在瀏覽器可用時自動存入 localStorage（`lumen-cinema-layout-editor-v1`）；對話內會讀寫 `window.openai.widgetState`。
- 某些沙箱不能使用 localStorage，工具仍可使用。明確匯出 JSON 可跨瀏覽器／對話攜帶，不假設儲存一定成功。
- 「匯出／匯入配置」可複製、下載 `lumen-cinema-layout.json` 或貼上匯入。匯入先完整驗證，錯誤不會部分覆寫目前資料。
- 有支援的對話環境顯示「把配置交給 Codex」，由使用者按鈕發送配置；文字明確要求先更新設計預覽，仍待確認後才實裝及更新 Pages。
- 配置類型為 `lumen-cinema-layout-draft`、schema 1。與正式 `lumen-cinema-v2` 遊戲存檔分開，不能作正式存檔匯入。
- 所有房間名稱、大小及 ID 固定；匯入不執行任何程式或直接注入文字為 HTML。

## Verification

qa.json 記錄真實 Chromium 流程：拖放吸附、越界／重疊、待放區、觸控、鍵盤、地板筆刷、入口連通、開局預覽、復原／重做、JSON 下載／匯入、錯誤匯入原子性、離線、重新載入、320px 排版、對話沙箱儲存及交接訊息內容。

editor-default.png、editor-mobile.png 為實際畫面。手機驗證為模擬觸控，未宣稱實機驗證。

## Boundary

尚未接入最終可玩地圖、財務或存檔。使用者現已要求同步 GitHub，工具及已確認預覽由既有 Pages workflow 公開；建造／擴建玩法仍待整體設計確認後實裝。
