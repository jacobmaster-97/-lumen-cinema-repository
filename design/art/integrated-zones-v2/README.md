# 一體化方塊區域 v2 — 待使用者確認

## Current scope

使用者要求將售票、小食、洗手間從散件拼貼改為區域一體化貼圖，再指定刪除後勤室設計，每區以方塊／四邊形為單位。

本版只交設計。沒有修改 prototypes/browser、src/assets/cinema/runtime 或 GitHub Pages，也沒有改動已上線存檔與營運規則。

## Design

- 三區統一以 8×8 格正方形為設計目標；2:1 等角投影呈完整四邊形，不切角、不做 L 形或額外門口凸台。
- 館內共用深藍／墨綠牆面、酒紅櫃枱、象牙色地板、黃銅線條；地板、牆、櫃枱與固定設備一次設計。
- 售票：雙服務位、兩部自助售票機、電影燈箱及後方工作位。
- 小食：雙服務位、集中後吧、爆谷／汽水／熱食／冷藏設備。
- 洗手間：標準及無障礙廁格、雙盆、鏡面與乾手機、入口遮擋。
- 後勤室不在本次設計範圍；v1 的 staff.png 已移除。v1 其餘三張只作修改來源，v2 是本次確認版本。

## Files and preview

- tickets.png、snacks.png：1536×1024 RGBA；toilets.png：1585×992 RGBA。
- prompts.json：完整生成指令及原創素材方向。
- preview.html：以相同目標底面四角映射三張原始 PNG，展示相同比例，並可開啟 8×8 格網；只供美術確認，不代表已實裝。
- review.png：同頁真實瀏覽器截圖；qa.json：來源雜湊、尺寸、預覽檢查及交付邊界。

## Integration contract after approval

一體化指整體美術設計，不將整區壓成不能遮擋人物的單一執行期圖層。確認後才處理透明邊緣、精確格網、透視與牆高，拆分 base／rear／counter-front／partition-front 等圖層；保留人物、污漬、升級設備為動態層。

現有來源有半透明外圍光暈及少量邊緣雜色，預覽以輪廓遮罩檢視房間。實裝前需正式清理，不把此設計原檔宣稱為已完成匯入的 runtime 素材。實際地圖位置、門口、工作通道、顧客路徑、碰撞、升級相容與深度遮擋需在使用者確認後一併驗證。

下一步：使用者確認三區的方塊形狀、整體美術與設備佈局；得到確認才實裝。
