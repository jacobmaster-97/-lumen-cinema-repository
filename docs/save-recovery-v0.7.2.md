# v0.7.2 重新開啟與存檔保護

使用者按「繼續已儲存進度」後發現要重新佈置。一般引擎存讀檔可以保留已建成地圖；已重現的缺陷在瀏覽器生命週期：頁面啟動先建立暫時空白新局，歡迎視窗尚未讀檔，再次重新整理／離頁會觸發pagehide自動儲存，將舊進度覆蓋。之後按繼續讀到的已是空白新局。這不是正常建造規則。

## 重現與驗證

scripts/verify-save-reopen.cjs 建立完成4區域的起始影院，真實經營一日後存檔。原0.7.1重複重新整理歡迎畫面再按繼續，區域4→0、資金44792.04→68000、日期2→1，見production/verification/v0.7.2/baseline.json。這證明會造成同樣現象的路徑，並未讀取使用者iPad上的實際存檔，不能確定其檔案目前是否已被覆蓋。

## 正式行為

- 開啟頁面後先載入現有存檔，再顯示「繼續已儲存進度」。歡迎視窗的關閉或重載不會選擇新局。
- 只有成功還原，或確定沒有存檔／玩家確認重新開局後，才允許自動儲存。素材尚未載入、讀檔失敗時保留原始檔案，不以暫時新局覆蓋；讀取失敗時停用開業／繼續按鈕。
- 有可讀較早備份時提供「查看較早備份」。先預覽日數、資金、分店及區域／地板數；取消不改資料，明確確認才恢復。候選來自既有before-flow-v1／before-strategy-v1／before-map-v1及新before-reset／before-recovery，各檔先經原引擎驗證，優先較高日數、同日較新備份。
- 恢復前另存現有原始檔；重新開局前也另存原始檔。備份寫入失敗就取消該操作，不先重設戲院。這些備份是較早時間點，無法保證還原最後一刻進度；沒有有效備份便不虛構補錢或建築。
- v2存檔結構、地圖及開業規則、資金／所有權／升級／排片、0.7.1效能修正保持。只有確認重新開局會重設建造進度。模組快取版號0.7.2。
