# 光影大亨 · 可玩瀏覽器原型 v0.2

使用 Codex Game Studio 規劃及驗證，瀏覽器執行層為原生 ES modules + Canvas 2D。直接載入 src/assets/cinema 的實際透明 PNG 圖集，Godot 相容來源及貼圖測試仍保留。

## 試玩流程

1. 檢查開業排片、售價及員工崗位，按「開始營業」。
2. 正常速度一日 180 秒；可用 2×／4× 加速，但不能跳到事件。
3. 事件可選擇交員工、付費補救或玩 20 秒操作小遊戲。
4. 日結後查看營運報告，再籌備下一日。
5. 在「裝修與物業」買斷免租，或以 $54,000 開設觀塘第二店。
6. 第二店需要親自排片與配置人手；兩店共用日期及資金，各自計收支。

所有進度只存在本機瀏覽器，沒有離線收益。切換分頁會暫停，重新讀取營業中存檔亦會暫停，需按「繼續」。

## 已實作

- 兩店等角場景，9 件設施貼圖、程序繪製像素客人與員工活動。
- 影廳時間軸、片長與清潔緩衝檢查、電影／場次票價、複製昨日及主動套用排片建議。
- 6 類客群、20 部戲仿電影資料，分批每週上映，口碑型電影較慢退熱。
- 票房分帳、大片較高抽成、食品收入與成本、薪金、租金、維護、投資與貸款現金流。
- 員工聘請、崗位調整、培訓、解除聘用；自動排班。
- 食品定價與解鎖、指定區域設施升級、物業買斷及第二分店。
- 單店每日一般 0–2 次事件，包含停映、謝票、維修及售票／小食／清潔繁忙事件。
- 三種可選短操作小遊戲，額外收益受實際需求、座位及服務能力限制。
- 本機自動／手動存檔與讀檔、分店日報、客群構成。

## 素材與限制

地板與牆為程序繪製材質，角色為簡單像素人物；正式方向動畫、聲音、特別格式、完整影展及大量裝修尚未加入。海報是程式繪製的原創戲仿圖案，並非現實電影素材。數值及最終日長需要使用者試玩調整。

## 測試

在此目錄執行 `npm ci --ignore-scripts`，再執行 `npm test`。只有 DOM 測試需要 jsdom；遊戲本身無第三方執行依賴。17 項純模擬測試加 1 項跨畫面 DOM 整合測試，並非視覺瀏覽器試玩。

`index.html`, `game.css`, `game.mjs`, `engine.mjs`, `render.mjs` 與同層 `assets/` 構成靜態版本。部署由 Sites 工作流程處理；既有貼圖工作台保留於 art.html。
